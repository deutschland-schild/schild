# Personas und User Stories

Für wen wir Schild bauen und was Schild für diese Menschen leisten muss. Alles hier ist ein Entwurf aus der Discovery. Die Personas sind erfunden, ihre Zitate sind angenommene Wünsche und keine Kundenstimmen. Die Stories beschreiben Ziele; was vom Schild Gateway gebaut ist, steht in [docs/gateway](../gateway/README.md).

Format, Status und Regeln für Story-IDs stehen in [00-ueberblick.md](00-ueberblick.md).
