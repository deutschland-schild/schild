# TEST ONLY keys

**These keys are public. Never use them outside the local test lab and the unit tests.**

- Seeds: `sha256(seed_domain + name)` with `seed_domain` `schild/testkey/v0/` unless the entry names another one; anybody can recompute them and sign anything.
- Key ids start with `test-`, except the test lab's own keys listed since v0.2 (D24): `testlab-lab-d-online`.
- Builds with `-tags release` refuse every one of these keys (by key id prefix or listed key id, and by public key, `contract/keys.IsTestKey`), refuse the `contract/testkeys` package (it does not exist there) and refuse the test profile in `schild.yaml` and `lab.yaml`.
- [keys.json](keys.json) is generated by `make contracts-vectors`; `go test ./testkeys` and the Python cross-check both re-derive every public key from its seed.

