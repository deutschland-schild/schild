# Contracts v0.5 (stage 1, spec MVP-01; v0.3 for MVP-11, v0.4 for MVP-17, MVP-18, MVP-19 and MVP-21, v0.5 for MVP-22)

Everything that flows between Schild components, fixed before any component is built. Status: **v0, frozen** ([VERSION](VERSION), [CHANGELOG.md](CHANGELOG.md)) after an adversarial review on 2026-10-26. The wire format, the check order and the vectors are fixed; the items marked OPEN in [DECISIONS.md](DECISIONS.md) are deployment and policy questions for the initiator and do not change v0. Changes after the freeze only through the initiator with a new version. **v0.1** (2026-10-26) is a backwards-compatible addendum requested by the component teams: lab co-signing protocol with peer-authenticated requests, the public log root as RFC 6962 tree hash, and dashboard API additions ([cosign.md](cosign.md), [CHANGELOG.md](CHANGELOG.md), DECISIONS D22). Nothing in v0 changed meaning; every v0 vector is unchanged. **v0.2** (D24, initiator): `Relay.kind` in the lab dashboard API (relays and peer labs apart, derived from signed stream subscriptions of configured peers) and lab-d's test lab key `testlab-lab-d-online` in `testkeys/` ([CHANGELOG.md](CHANGELOG.md)). **v0.3** (D25, MVP-11): server check and agent - host report `schild.host_report/0.1`, signed agent delivery (kind `agent-report`), enrolment, revocation, gateway ack, `host_check` in `schild.yaml` and the hosts/agents operations of the client dashboard API ([host-check.md](host-check.md)). **v0.4** (D29, MVP-17; D30, MVP-18): behaviour across requests and rate limits, extended by distributed attacks (`behaviour.distributed`, events `schild.distributed.detected.v1` and `.ended.v1`, wave operations). MVP-17: `behaviour` in `schild.yaml` (five fixed scenarios with mode `off` | `observe` | `challenge` | `block` and optional thresholds, preset limits, own rate limits), the local events `schild.behaviour.triggered.v1` and `schild.ratelimit.exceeded.v1`, and the behaviour operations of the client dashboard API. Local only; signals are unchanged. MVP-19 (D31, same unreleased v0.4): `network.enabled: false` in `schild.yaml` (gateway without labs, relays and keys; network fields rejected), `ingress.caddyfile`, `ingress.storage` and `ingress.unprotected_sites` (schild as ingress with the operator's Caddyfile, exclusive with `upstream` and `listen.proxy`), and `network` (`off` | `connected` | `degraded`) in the client dashboard API. MVP-21 (D33, same unreleased v0.4): `monitoring` in `schild.yaml` (on by default, three fixed rings in `metrics.db`), the `monitoring` operations of the client dashboard API (now, live stream, series, breakdowns, server snapshot, catalogue, raw buckets; `MetricBucket` is the unit of the MVP-20 export) and the Go package `contract/monitoring`; an agent API on its own loopback listener, read only except the CrowdSec Hub switch (D39 amendment) and single blocks (D42) (`agent_api` in `schild.yaml`, [api/gateway-agent.openapi.yaml](api/gateway-agent.openapi.yaml), served by the gateway itself since D61, `contract/agentapi`). Addendum of 2026-10-28: `waf.max_concurrent_evals` and `waf.queue_wait_ms`, behaviour reason `learning`. Addendum of 2026-10-29 (MVP-22 `MVP-21 addendum`): breakdowns by referrer, browser, OS, device, bot category and rule, counters `page_views` and `detections`. **v0.5** (D35, MVP-22, backwards compatible): the request ring without IP addresses (`monitoring.requests`), bots (`bots`, [bot-catalogue.schema.json](bot-catalogue.schema.json), matching and verification in `contract/bots`), geo enrichment with the operator's own IPinfo or MaxMind key (`geo.provider`, field mapping in `contract/geo`), the `requests` operations of the client dashboard and agent APIs (`contract/requests`), and result vectors (`bot-match`, `geo-map`) that compare the classifier output of Go and Python.

Gate: `make contracts-test` (from the repository root) validates every golden vector with the Go reference implementation (`contract`) and with an independent Python implementation (`tools/crosscheck.py`) and fails on any difference.

## Using the contracts from a component

```go
import (
    "github.com/deutschland-schild/schild/contract"
    "github.com/deutschland-schild/schild/contract/config"
    "github.com/deutschland-schild/schild/contract/verify"
)

lab, err := config.LoadLab("")                   // $SCHILD_LAB_CONFIG or /etc/schild-lab/lab.yaml
ctx := &verify.Context{Trust: peers, Threshold: 3, Channel: lab.Channel}  // peers: trusted lab keys
ctx.Now, ctx.State = time.Now(), state           // rollback protection
res, err := verify.Signed(contract.KindBundle, raw, ctx)
if err != nil { log(contract.CodeOf(err)) }      // stable error code
bundle := res.Value.(*msg.Bundle)
```

Regenerate vectors after changing a schema or a check: `make contracts-sync contracts-vectors contracts-test`.
